# 数据说明

`data/lerobot/six_objects_60/` 是供各模型共用的 LeRobot v3 数据集。`meta/info.json` 记录 60 段、36,000 帧、30 FPS、三路 640×480 图像，以及各 16 维的 `observation.state` 和 `action`。六种任务各有 10 段录像。`data/demonstrations/` 只保存精选原始示教和回放计划，不是完整的原始采集备份。

转换采用共同的 30 Hz 时间栅格、最近相机帧及前一个动作/反馈值保持。原采集时间戳来自主机，不是三相机同步曝光时间。数据中有重复回放的示教，因此不能把 60 段视作 60 条独立的人类演示；评估应按 episode 划分，不能随机拆帧。原始夹爪反馈可能超出 `[0,1]`，不要在模型之外静默截断。

转换检查确认了文件结构和基本时间对齐，**没有确认每段都抓取成功**。发布前应逐段复核任务标签、图像隐私和动作质量。当前 `meta/info.json` 只定义 `train: 0:60`，没有独立测试集。
