# OpenArm 六类物品抓取

本项目基于双臂 OpenArm 和三路 RGB 相机开展模仿学习实验，任务是从洞洞板上取下指定物品并放入接收盒。实验覆盖螺丝刀、透明胶带、双面胶、整包抽纸、黑色胶带和红色胶带，使用同一套示教数据训练 ACT、SmolVLA、OpenVLA-OFT 和 π₀。ACT 按物品分别训练，其余三种策略采用多任务配置。

## 项目目录与训练环境

| 目录 | 内容 |
| --- | --- |
| [数据集](data/) | 60 段、36,000 帧的 LeRobot 数据，30 FPS，含三路相机和 16 维状态与动作。另有精选示教和数据说明。 |
| [训练脚本](training/) | 四个模型的训练入口和补丁。采集、数据转换、ROS 2 控制及相关源码放在 [ROS 2 控制子目录](training/ros2_control/)。 |
| [推理视频](inference_examples/README.md) | 26 段三视角真机录像，覆盖四种模型的全部任务，包含失败与中断案例。 |

**ACT、SmolVLA 和 π₀ 在本地 NVIDIA RTX 4090 上完成任务训练与微调。OpenVLA-OFT 在租用的 NVIDIA L40S 服务器上微调**，训练后的检查点下载到本地进行真机验证。

## 真机验证结果

据最新现场确认，ACT 在本组六次试验中成功 **4 次（66.7%）**。展示录像可复核四次取件，涉及双面胶、透明胶带、红色胶带和抽纸。各段的释放与入盒证据见录像索引。

ACT 和 OpenVLA-OFT 采用现场确认结果。OpenVLA-OFT 按动作块长度分别记录成功次数，各配置的总试验次数待补录。SmolVLA 和 π₀ 各复核六段主录像，确认目标物释放并留在接收盒内时计为成功。

| 模型 | 确认成功次数 | 成功比例 | 判定依据 |
| --- | ---: | ---: | --- |
| ACT | 4/6 | **66.7%** | 现场确认 |
| SmolVLA | 3/6 | **50.0%** | 录像确认入盒，另有一段结果待确认 |
| OpenVLA-OFT（chunk 8） | 0 | — | 现场确认 |
| OpenVLA-OFT（chunk 30） | 2 | — | 现场确认 |
| OpenVLA-OFT（chunk 15） | 1 | — | 现场确认 |
| π₀ | 3/6 | **50.0%** | 录像确认入盒 |

ACT 的原始录像复核、逐段结果和来源见 [推理录像索引](inference_examples/README.md)。

## 真机验证中的问题与分析

1. **OpenVLA-OFT 的动作块长度与推理延迟。** 初始配置每次预测 8 帧，按 30 Hz 执行仅覆盖约 0.27 秒，真机调试中出现了动作衔接不畅。随后试验了 30 帧（约 1 秒）。采用归一化流程的 30 帧版本真机效果欠佳，之后调整为 15 帧（约 0.5 秒）。三个数值均为动作块帧数。归一化设置、动作块长度和训练配置的影响仍需通过受控对照区分。
2. **关节误差与速度限制影响实际轨迹。** 模型目标与当前实测位置之差影响指令能否下发。控制目标与后续反馈之间的跟踪误差反映执行偏差，关节限速则影响目标到达时间。诊断时应对齐模型输出、桥接下发目标和实测关节反馈，以定位误差产生的环节。
3. **小模型在本任务中表现出竞争力。** SmolVLA 在部分物品上的动作衔接和放置表现优于本项目测试的 OpenVLA-OFT 配置。SmolVLA 和 π₀ 在所选录像中均有三段确认入盒。模型规模的影响仍需在一致的起始条件、执行配置和试验次数下比较。
4. **π₀ 出现指令与执行手臂不匹配。** 一次现场试验中，透明胶带任务原应由左臂执行，模型却产生了右臂抓取抽纸的动作。可固定图像和关节状态，仅替换任务指令，离线比较两侧手臂的动作输出，检验模型对指令变化的响应。索引中的透明胶带片段根据其自身画面判定为未入盒。
